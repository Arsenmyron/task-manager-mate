#
Task Management App is a web application for managing tasks and projects.
You can create, view, update, delete and change the status of your tasks,
as well as manage work items, tags and task types.

Features
-Create and manage tasks: add new tasks, view details, update and delete.

-Change task status: mark tasks as completed or incomplete.

-Manage tags, task types and positions: add new tags, task types and work positions, as well as delete them.

-Worker registration: ability to create new workers in the system.
